Dapur Kilat is an original cooking game for the desktop browser: you run the kitchen of a busy
Indonesian street-food stall at rush hour. Take orders off the board, gather ingredients from
the crates, chop on the boards, fry in the woks, boil the pot, steam the rice, plate the dish
and ring the bell at the serve window before each customer's patience runs out. Three days of
service, recipes that unlock as you go, combos for a clean streak and burnt pans when you linger.

Built from static files with no network requests: vanilla ES modules drawing every sprite in
code, with synthesised WebAudio sound. Serve game/ with any static server and open
game/index.html in desktop Chrome; node serve.ts starts one at http://localhost:8080.

## Run it

```sh
node serve.ts
```
